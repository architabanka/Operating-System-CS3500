7. The kernel crashes because num = *(int *)0 attempts to read from virtual address 0. 
Address 0 is not mapped in the kernel address space (as can be inferred from the fig), so the load instruction at sepc = 0x80001ca8 causes a page fault. 
The value scause = 0xd confirms that the exception is a load page fault (as per riscv specification), while stval = 0x0 confirms that the faulting address was 0. 
The riscv trap mechanism transfers control to the kernel's trap handler, which detects the unexpected kernel exception and calls panic("kerneltrap").
